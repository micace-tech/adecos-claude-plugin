# Affiliate network notes

Checked 2026-10. Programs can override network defaults — the program's own terms win. "Not confirmed" means no official source was found; ask the user or check the dashboard.

| Network | Statuses / lifecycle | Validation & payout | Source |
|---|---|---|---|
| Impact | Pending until the action's **Lock Date**; brand can modify/reverse until then, final after | Per program | help.impact.com — pending actions |
| Awin (incl. former ShareASale) | Pending → Approved/Declined; advertiser sets validation window; unreviewed commissions auto-approve after it | Average approval 30–45 days; declines include cancellations, returns, duplicates, fraud, illegitimate PPC | help.awin.com/docs/validating-transactions |
| ShareASale → Awin | Migrated 2025; exports show "sas-cts"; old "afftrack" is now clickref2 | — | success.awin.com upgrade article |
| Refersion | Pending, Approved, Denied, Unqualified (outside attribution window); approved cannot be changed | Auto-approve on by default after 90 days (minimum 30) | support.refersion.com auto-approve |
| UpPromote | Refund creates a **negative** referral that also needs approval | Suggests 30-day approval delay | docs.uppromote.com refund |
| FirstPromoter | Refunds create negative commissions | — | docs.firstpromoter.com refund API |
| PartnerStack | Pending approval / Hold / Paid; hold length per program | Usual payout on the 13th; minimum withdrawal $5 | support.partnerstack.com |
| Tapfiliate | pending / approved / disapproved; auto-approve after a configured review period | Period length not confirmed | support.tapfiliate.com commissions report |
| Everflow | All reports use the **network's** time zone — top cause of mismatches | — | helpdesk.everflow.io reports |
| CJ | EPC is shown **per 100 clicks** (divide by 100 before comparing with CPC); 7-day EPC needs ≥100 clicks, 3-month EPC ≥1,000 | Lock periods not confirmed | CJ terms quoted by merchants |
| Involve Asia | Pending Advertiser Validation → Pending Advertiser Collection → Available to Withdraw; validation starts the 1st of the following month, 14–60+ days | Minimum ~MYR 40–80 (pages disagree) | helpcentre.involve.asia |
| Ecomobi | Pending until delivery confirmed; roughly 85% of estimated commission gets approved | Shopee validation ~3 months (older page) | ecomobi.com guide |
| Accesstrade | Validation time set per campaign | Payments from the 15th to month end above a minimum; VN threshold not confirmed | academy.accesstrade.global |
| MasOffer, GoAffPro, Rakuten | Not confirmed | Not confirmed | — |

Google Ads side: up to 15–48 h conversion delay; review a day's data the following day (support.google.com/google-ads/answer/2404039).
